# করণীয় তালিকা (To-Do App)

একটি সহজ, বিজ্ঞাপনহীন অ্যান্ড্রয়েড To-Do অ্যাপ। বাংলা ও ইংরেজি দুই ভাষাতেই চলে।

A simple, ad-free Android To-Do app with Bangla and English UI.

## ফিচার / Features
- কাজ যোগ করা, টিক দেওয়া, মুছে ফেলা / Add, check off, delete tasks
- ফোনে স্থানীয়ভাবে সংরক্ষিত, ইন্টারনেট বা অনুমতি লাগে না / Saved locally, no internet or permissions
- Kotlin + Jetpack Compose

## ইনস্টল / Install
[Releases](../../releases) পেজ থেকে সর্বশেষ `todo-app.apk` ডাউনলোড করে ফোনে ইনস্টল করুন।
(ফোনের সেটিংসে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে।)

## বিল্ড / Build
`gradle assembleRelease` অথবা Android Studio দিয়ে প্রজেক্ট খুলুন।
